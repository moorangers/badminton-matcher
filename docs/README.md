## หลักการอัปเดตเอกสาร

- เอกสารเหล่านี้เป็น **living document** — เมื่อมีการตัดสินใจใหม่หรือ implement ฟีเจอร์ตามแผนแล้ว ให้กลับมาอัปเดตสถานะในไฟล์ที่เกี่ยวข้อง (โดยเฉพาะ `decision-log.md` และ `roadmap.md`)
- ห้ามเก็บสิ่งที่ derive จากโค้ดได้อยู่แล้ว (เช่น รายชื่อไฟล์/โครงสร้างโฟลเดอร์แบบละเอียด) ไว้ในนี้ เพราะจะ desync กับโค้ดจริงเร็ว — ให้ชี้ไปที่ไฟล์จริงแทน
